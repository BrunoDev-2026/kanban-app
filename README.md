## ✨ Visão Geral

O **MB FlowBoard** é uma aplicação de gerenciamento de tarefas premium, projetada com uma estética moderna e foco total na experiência do usuário. Desenvolvido com tecnologias web nativas, ele oferece um ambiente fluido para organizar seu trabalho com eficiência e estilo.

> [!NOTE]
> Projeto desenvolvido com **JavaScript Vanilla**, sem dependências externas, garantindo performance e leveza.

---

## 🚀 Principais Recursos

O projeto foi construído pensando na produtividade inteligente:

- 🎯 **Quadro Kanban**: Gerenciamento visual e intuitivo.
- ⚡ **Drag & Drop**: Movimente tarefas entre colunas com facilidade.
- 📊 **Dashboard de Métricas**: Tenha clareza total sobre o que importa.
- ⏲️ **Pomodoro Inteligente**: Mais foco, menos distração.
- 🏷️ **Tags e Prioridades**: Organize suas tarefas com detalhes que fazem a diferença.
- ⌨️ **Atalhos de Teclado**: Ganhe velocidade no seu dia a dia.
- 🎨 **Temas Customizáveis**: Escolha entre diversos temas (Dark, Light, Neon, Glass).
- 💾 **100% Local e Seguro**: Seus dados ficam apenas no seu navegador (`localStorage`).
- 📱 **Responsivo**: Perfeito para qualquer tamanho de tela.

---

## 🛠️ Tecnologias Utilizadas

O projeto utiliza o que há de mais moderno no desenvolvimento web nativo:

- **HTML5** (Semântico e Acessível)
- **CSS3** (Grid, Flexbox, Variáveis, Animações e Glassmorphism)
- **JavaScript ES6+** (Lógica modular)
- **LocalStorage API** (Persistência de dados)
- **HTML5 Drag & Drop API** (Interatividade nativa)
- **Google Fonts** (Tipografia Premium)
